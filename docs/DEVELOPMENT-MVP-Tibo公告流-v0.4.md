# 重置雷达 MVP v0.4：Tibo 公告流

更新时间：2026-09-15  
状态：本地可运行原型

## 1. 本轮目标

把网站从单一“信号仪表盘”调整为用户一眼能看懂的重置情报页。布局参考成熟的重置追踪产品，但保留项目原有的深绿、荧光绿和青绿色视觉体系。

核心路径：

1. 用户先看到最近一次重置距离现在多久。
2. 继续看到累计次数、平均间隔、最长间隔。
3. 用 26 周热力图判断重置节奏。
4. 阅读 Tibo 的重置公告，并一键打开对应的 X 原帖。

## 2. 页面结构

- 顶部：Tibo 头像、姓名、X 账号和雷达在线状态。
- 简介：说明网站追踪对象和作用。
- 核心状态卡：最近一次重置、准确时间、动态雷达。
- 数据卡：累计公告、平均间隔、最长间隔。
- 历史热力图：按“额度重置 / 重置卡 / 重置信号”分类。
- 公告时间线：中文摘要、英文原文、时间、类型、Tibo 头像。
- 页脚：原型数据和非官方声明。

## 3. MVP 交互

- 点击顶部头像、名字或“关注 Tibo”，打开 `https://x.com/thsottiaux`。
- 点击任意公告卡，打开该公告对应的 X 原帖，而不是统一跳主页。
- 点击热力图中有颜色的日期，查看当天公告类型。
- 点击筛选项，联动淡化其他类型的热力图记录，并筛选公告列表。
- 点击“分享当前状态”，优先调用系统分享；不支持时复制文字。
- 点击“展开更多公告”，在当前页展开其余原型记录。

## 4. 数据与边界

- 当前数据来自 Tibo 的公开 X 帖子及公开重置历史页，页面明确标记为“公开数据原型”。
- 当前记录数为 53，平均间隔 6.9 天，最长间隔 67.7 天；统计更新时间为 2026-09-12。
- 目前没有自动采集、登录、付费、邮件、短信或电话提醒。
- 历史规律不等于预测；个人额度以 Codex 产品内显示为准。
- 网站与 OpenAI 无隶属关系。

## 5. 下一步建议

在域名和服务器确定之前，下一步只需补齐“自动更新数据”这一项。推荐先做一个公开 JSON 数据源，每次更新后重新生成页面；等准确率稳定，再考虑提醒功能和商业化。
