## 已落地

- 保留 AIHOT 的 React Router 前端、Fastify API、PostgreSQL、后台和内容采集架构。
- 雷达总览、Codex／Claude／Grok 独立记录、公告详情、搜索与类型筛选、精选副业、使用指南。

- 原帖文字、公开来源、发布时间、适用范围；分享文字保留原帖与个人额度免责声明。

- /codex-reset 使用迁移快照中的 Codex 原始公告，不接入上游“时间经过即推断完成”的显示逻辑。
- 修复依赖树中 fflate 的已知中危问题，锁定 0.7.5。

## 不能误认成已完成的功能

当前是 **截至 2026-09-28 21:00（北京时间）的旧站快照**，并非实时采集结果；旧站有未覆盖后续公告的风险。
导入时不重新认证历史内容。上线前必须逐条对照最新官方原帖，尤其是“将重置”是否已有后续确认。

新采集、飞书、订阅、分享海报与每周生财更新均未迁移启用。
不读取个人账户，不显示未经证实的个人额度或准确倒计时，不把时间经过当作完成证据。
上游的 Codex 自动监控仍关闭：其中“过期后推定完成”的展示不能直接用于本产品。模型榜只读展示已开启，本地预览不运行 worker，因此不自动抓取评测或产生模型费用。

## 本机运行

Node 24.11+。首次安装：

```sh
npm ci
npm run build -w @aihot/web
node scripts/local-preview.ts /绝对路径/旧站/website/data/public-snapshot.json
```

后续启动只需：

```sh
node scripts/local-preview.ts
```

- 页面 http://localhost:3210 ，API 仅监听 127.0.0.1:3211，独立数据库仅监听 127.0.0.1:55439。
- 数据和随机密钥仅在 Git 忽略的 .data/local-preview 内，密钥文件权限 0600。
- 不安装系统服务、不创建操作系统用户；Ctrl+C 停止本轮预览，数据库保留。
- 不启动 worker；强制关闭采集、真实模型、飞书与 IndexNow。
- embedded-postgres 如被 npm 安装脚本策略拦截，需要允许其对应系统包的 hydrate-symlinks 安装脚本。不要启用 createPostgresUser。
- 这是 Mac 开发辅助方式，不能原样暴露到公网。

## 正式上线顺序

首轮迁移验证：类型检查、生产构建通过；独立干净数据库的 133 项后端测试与 12 项页面／缓存测试全部通过；桌面 1440px、手机 390px 的导航、搜索空态、类型筛选、详情、案例展开、主题切换与刷新已实测。npm audit 未报告已知漏洞。旧站工作区状态未改动。

导航与视觉修订：深绿雷达主视觉、浅色内容卡、功能快捷入口；恢复完整分类，不再隐藏底座内容功能。新增导航和未接入评测的回归测试，133 项后端 + 13 项页面测试通过；26 个页面及 API、RSS、MCP 等机器出口检查通过。未推送或部署。

首次测试曾因关闭模型替身及重复使用受污染的测试库出现失败，现已改为每次独立临时测试库、仅测试进程使用本机模型替身，预览服务的真实模型开关仍关闭。客户端导航的 .data 路径识别问题已修复并加入回归测试。

1. 确认部署：推荐一个运行 Web／API／worker 的常驻 Node 服务 + PostgreSQL；当前 Vercel 静态／无服务器部署不能直接承载原样架构。Docker Compose 方案见 docs/deploy.md。主域名切换前保留旧站回退。
2. 信源接入：沿用三个平台的官方公开来源，统一规范为预告／确认／重置卡／更正。复用 AIHOT 的请求留痕、预算和重试机制。上游原生仅有 Codex 监控，Claude、Grok 需要单独适配与验收，不能仅换账号名。
3. 明确重置可自动发布；模糊记录进入待核验，不公开成已确认。完成信源账号归属、去重、时间戳、原帖撤回和更正测试。
4. 比较 SocialData 的付费接入与现有采集渠道，确定预算及密钥存储后再启用。不要默认开启原项目演示信源。
5. 同一 publication 数据源驱动网页、重置 RSS、分享卡和飞书，凭据只在服务器；通知幂等，任务失败明确显示陈旧状态。
6. 精选副业每周一次，继续生财 MCP → 去重 → 标准筛选 → 摘要／问题检查 → 发布 → 通知；不公开会员全文，商业数据标作者自述。
7. 自有域名、旧路径重定向、SEO／RSS／MCP 数据一致性、许可及隐私条款复核、备份恢复、手机与桌面验收后，再决定切换线上。

## 已确认方案：统一重置监控（2026-09-29）

- 侧栏只保留一个“重置监控”，去掉平台、Tibo 的重复入口；其他 AI 内容、工具和服务栏目保留。
- /monitor 为全部平台；/monitor/codex、/monitor/claude、/monitor/grok 为页内可分享标签。
- 监控页包含公告概览、来源、真实历史快照时间、原帖、类型筛选、搜索、信源规则；Tibo 是 Codex 的信源而不是平台。
- 旧 /platform/:provider 与 /codex-reset 返回 302 到对应监控标签；未知平台仍为 404。
- 继续只显示已导入数据，不使用设计图里的示例公告。新采集、账户额度和自动通知均未开启。
- 本轮 133 项后端测试、14 项前端测试通过；类型检查、生产构建、页面和机器出口连通检查通过。
