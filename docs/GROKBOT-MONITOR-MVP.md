# GrokBot 方案迁移说明

这个方案已经停用，不再作为“重置雷达”的正式数据入口。

## 停用原因

- 依赖 X 网页登录和云电脑会话，容易受到验证码、掉线和页面改版影响。
- 无法证明每次都取得完整原文和稳定的帖子列表。
- 增加了用户账户权限和订阅成本。

## 当前正式方案

项目已经改为在站长 Mac 上每天北京时间 11:00 运行独立采集器：

- 读取公开 JSON，不需要登录 X；
- 只接受 `@thsottiaux` 本人内容；
- 明确重置自动发布；
- 含糊内容不公开，只发飞书等待决定；
- 通过数据校验、测试和正式构建后才允许推送 GitHub。

完整配置与验收步骤见 [`MAC-TIBO-MONITOR-MVP.md`](./MAC-TIBO-MONITOR-MVP.md)。
