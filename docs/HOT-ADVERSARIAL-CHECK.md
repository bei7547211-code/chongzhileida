## 已接入

复用底座 RSS 读取器及网络安全防护，单独存储“原始资讯短摘要”发布视图，
不经过付费模型，不冒充已评分、已聚合的热点事件。

- OpenAI News、TechCrunch AI、The Verge AI：首次各 8 条。
- Google DeepMind、Hugging Face：首次失败，显示真实信源状态，不清空其他来源。
- 页面支持全部 / 官方与产品更新 / 技术媒体筛选，原文链接、原始日期、同步状态。
- 无翻译、无自动定时、无全网热度宣称；多来源聚合排名仍需后续处理流程。
- 新闻只写入本机数据库，不改变已在线的小程序同步内容。

手动同步（本地预览运行后）：

```sh
node scripts/sync-ai-news-local.ts
```

来源名单从 industry/sources.json 中选择固定 5 个；读取公开 RSS，丢弃正文和图片，
标题去标签、短摘要限 160 字符、链接只允许 HTTPS、去重复、跳过无日期和未来日期。
空响应或失败保留该来源的旧数据，保留上次成功时间，同时记录失败状态。
访客打开网页不会触发采集或模型调用。
