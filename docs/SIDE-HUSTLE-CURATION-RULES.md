# 精选副业收录规则

## 目标

从生财有术精华帖中挑选没有收录过的个人副业实战，生成脱敏解读并发布到网站。核心原则是绝不泄露原帖的解决方案，只展示作者成绩、这篇帖子解决的问题和少量原话，完整答案留在原帖。

## 项目固定位置

- 已收录数据：`website/data/side-hustles.json`
- 跳过名单：`website/data/side-hustle-skip.json`
- 素材目录：`website/public/side-hustles/`
- 数据质检：`website/scripts/validate-side-hustles.mjs`
- 网站列表：`/side-hustles`
- 体验卡：`/experience-card`
- 发布方式：推送 GitHub 的 `main` 分支，由 Vercel 自动部署
- 通知渠道：飞书群“重置雷达｜每日审查台”

## 选题规则

1. 使用生财官方 MCP 的 `searchTopic`，只查询精华帖，精简模式，每页十篇。
2. 按发布时间从新到旧评估，最多查看三页。
3. `entityType` 必须是 `xq_topic`，并排除已收录和已跳过的 `topic_id`。
4. 必须是个人实战复盘，有本人项目过程和可核验成绩。
5. 排除官方通知、招募、活动说明、团建游记和纯观点内容。
6. 优先选择标题含具体成绩数字、AI 相关或普通人可复制的副业案例。
7. 被排除的候选写入跳过名单，记录原因和日期。

## 全文与素材

1. 使用 `topicDetail` 拉取全文，优先读取 `articleContentContainFeishuDoc`，为空时读取 `articleContent`。
2. 头像保存为 JPEG，最长边不超过二百像素。
3. 第一张题图保存为 WebP，宽度不超过八百像素，只用于列表卡片。
4. 详情页不展示图片。

## 每篇固定字段

- 成绩板：一到三个真实结果，数字必须来自原文。
- 脱敏摘要：八十到一百四十字，只写背景、方向、周期和结果。
- 问题清单：四到六条，每条十五到四十字并以全角问号结尾，只提问题不写答案。
- 原作者原话：两到三句，每句十五到八十字，不摘录操作步骤或工具细节。
- 基础字段：标题、作者、发布日期、抓取日期、原帖链接、互动数据、正文长度、标签、头像和封面。

## 文字边界

- 摘要和问题清单使用全角标点，不使用半角逗号。
- 不使用破折号。
- 不生成关键要点、操作流水线、方法拆解或任何可照着执行的步骤。
- 不编造成绩、作者观点或互动数据。
- 页面明确提示答案在原帖里，并提供原帖和体验卡入口。

## 质检和发布

1. 追加数据前检查 `topic_id` 不重复。
2. 运行 `npm run validate:data`，检查字段、字数和标点。
3. 运行自动测试和生产构建。
4. 发布后确认列表页、详情页和体验卡页面均返回成功。
5. 首篇人工验收通过后，再考虑启用每两天一次的自动收录。自动化运行时仍必须遵守只读检索、脱敏输出和失败停止原则。
